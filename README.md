# Ticket Rush

A retro, top-down help desk training game. You're the new Tier 1 tech at Ridgeline Logistics: answer calls, help walk-ups, and work tickets in a realistic Active Directory Users and Computers console and a ServiceNow-style ticketing system called FixFlow.

## Play

Open `index.html` in a browser, or play the hosted version once GitHub Pages is enabled.

## What it teaches

- Password resets, lockouts, onboarding, transfers, offboarding, contractor expirations, and domain trust errors in Active Directory
- Verifying identity, least privilege, and spotting social engineering
- Writing clear, safe ticket resolution notes

## Difficulty

Beginner (waves, slow clock, KB articles), Standard, and Expert (real-time shift).
